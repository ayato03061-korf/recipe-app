# レシピを考える（共有版）

冷蔵庫にある食材から今日の献立を探せるレシピ集です。全24品を収録し、食材・カテゴリ・条件（高タンパク／15分以内／作り置きOK）で絞り込めます。

公開ページ: https://ayato03061-korf.github.io/recipe-app/

## 公開方法（GitHub Pages）

1. このリポジトリに `index.html` を置く
2. リポジトリの Settings → Pages を開く
3. Branch で `main` ／ `/(root)` を選んで Save
4. 数分後に `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます

`index.html` は単一ファイルで完結しているため、ビルドやサーバーは不要です。

## 使い方

- 食材チップをタップすると、その食材を使うレシピが上に表示されます
- レシピカードをタップすると、材料（2人分）と作り方が開きます
- 選んだ食材や検索ワードのまま、クックパッド／クラシル／楽天レシピ／デリッシュキッチン／みんなのきょうの料理でも検索できます（外部サイトが新しいタブで開きます）。レシピ詳細から、その料理名で外部サイトを探すこともできます
- 「おまかせで1品決める」ボタンで、条件に合うレシピからランダムに1品選べます
